Guía de montaje · Windows

De cero a tu app funcionando en el móvil

Diez pasos, en orden. En cada uno te decimos qué hacer, por qué, y cómo saber que ha ido bien. Marca Hecho al terminar cada paso: esta página lo recuerda.

0 €Todo gratis
~45 minCasi todo es esperar descargas
0Conocimientos previos

Necesitas: un ordenador con Windows 10 u 11, tu móvil (Android o iPhone) conectado a la misma wifi que el ordenador, y un email. No hace falta Mac.

Parte 1 · Instalar los programas (una sola vez)
1

Instala Node.js

5 min · gratis

Es el "motor" que hace funcionar las herramientas de la app en tu ordenador. Sin él, nada de lo demás arranca.

Descargar Node.js ↗
  1. En la web, descarga el Windows Installer (.msi) de la versión marcada LTS.
  2. Ábrelo y pulsa Next hasta el final, sin cambiar nada.
  3. Si aparece una casilla "Automatically install the necessary tools", déjala sin marcar. No hace falta.
  4. Abre la Terminal: clic derecho en el botón de Inicio → Terminal (en Windows 10: busca PowerShell en el menú Inicio). Escribe esto y pulsa Enter:
node --version
Bien si… sale algo como v22.14.0 o v24.x (un número 20 o mayor).
¿Algo no va?
"node no se reconoce como nombre de un cmdlet…"
Cierra la Terminal y ábrela otra vez (se abrió antes de instalar Node). Si sigue, reinicia el ordenador.
2

Instala Git

5 min · gratis

Git guarda el historial de todos los cambios de tu app, como un "deshacer" infinito. Lo usan también Claude y GitHub.

Descargar Git for Windows ↗
  1. Descarga el instalador 64-bit Git for Windows Setup.
  2. Pulsa Next en todas las pantallas sin cambiar nada (son muchas; es normal).
  3. Cierra la Terminal, ábrela de nuevo y escribe:
git --version
Bien si… sale git version 2.xx…
3

Instala Visual Studio Code

3 min · gratis

Es el programa donde verás y cambiarás el código. Trae una terminal dentro, así tendrás todo en una ventana.

Descargar VS Code ↗
  1. Descarga la versión de Windows e instálala con las opciones por defecto.
  2. Recomendado: en la pantalla de opciones, marca "Add 'Open with Code' action…". Así podrás abrir carpetas con clic derecho.
4

Instala Expo Go en tu móvil

2 min · gratis

Expo Go abre tu app en el móvil mientras la construyes, sin publicarla ni compilar nada. Cada vez que guardes un cambio, lo verás en el móvil en un segundo.

Android · Google Play ↗ iPhone · App Store ↗

O búscala en la tienda de tu móvil como Expo Go. No hace falta crear cuenta.

Parte 2 · Preparar el proyecto
5

Pon el proyecto en su sitio y ábrelo

3 min

La carpeta del proyecto tiene que estar fuera de OneDrive (Windows suele sincronizar el Escritorio y Documentos, y se atasca con los miles de archivos de una app).

  1. Crea la carpeta C:\proyectos (en el Explorador: Este equipo → Disco local (C:) → clic derecho → Nuevo → Carpeta).
  2. Si te han pasado el proyecto en un ZIP: clic derecho → Extraer todo… → elige C:\proyectos. Si ya lo tienes en otra carpeta (como esta guía), muévela ahí.
  3. Si te han pasado un enlace de GitHub: en la Terminal escribe estos dos comandos, cambiando URL-DEL-REPO por el enlace:
cd C:\proyectos
git clone URL-DEL-REPO mi-app
  1. Abre VS Code → menú File → Open Folder… → elige la carpeta del proyecto (la que contiene package.json). Si pregunta "Do you trust the authors?", pulsa Yes, I trust.
  2. Abre la terminal de VS Code: menú Terminal → New Terminal (o Ctrl + ñ). A partir de aquí, todos los comandos se escriben ahí.
Bien si… abajo en VS Code ves una terminal que termina en algo como PS C:\proyectos\mi-app>
6

Descarga las piezas de la app

3–5 min

La app usa cientos de piezas ya hechas por otros (librerías). Este comando las descarga todas a una carpeta llamada node_modules.

npm install
Bien si… termina con algo como added 1100 packages. Los avisos amarillos (WARN, vulnerabilities) son normales.
¿Algo no va?
"la ejecución de scripts está deshabilitada en este sistema"
Windows bloquea por defecto los comandos de npm en PowerShell. Permítelo solo para tu usuario (es lo habitual al programar):
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
Responde S y Enter. Luego repite npm install.
"EPERM", "operation not permitted" o se queda colgado
Cierra VS Code, vuelve a abrirlo y repite. Si sigue, el antivirus o OneDrive pueden estar bloqueando archivos: comprueba el paso 5.
"npm no se reconoce"
VS Code se abrió antes de instalar Node. Ciérralo del todo y ábrelo otra vez.
Parte 3 · La base de datos (gratis, en internet)
7

Crea tu base de datos en Supabase

5 min · plan Free, sin tarjeta

Supabase guarda los datos de tu app (usuarios, notas…) en internet y se encarga del login. El plan gratuito sobra para desarrollar y para tus primeros usuarios.

Abrir Supabase ↗
  1. Regístrate (con GitHub o con tu email).
  2. Si te pide crear una organización: ponle tu nombre y elige el plan Free.
  3. Pulsa New project y rellena:
    • Project name: el nombre de tu app.
    • Database password: pulsa Generate a password, cópiala y guárdala en un sitio seguro (la necesitas en el paso 8).
    • Region: Europe (Frankfurt o Ireland), lo más cerca de tus usuarios.
  4. Pulsa Create new project y espera 1–2 minutos a que termine de prepararse.
Bien si… ves el panel de tu proyecto y ya no pone "Setting up project".
Ojo En el plan gratis, si nadie usa el proyecto durante una semana, Supabase lo "pausa". No se pierde nada: entras en el panel y pulsas Restore.
8

Conecta la app con tu base de datos

5 min · un asistente lo hace por ti

Este asistente guarda la dirección de tu base de datos en la app y crea las tablas (usuarios, notas) con sus reglas de seguridad. Solo tienes que contestar a lo que pregunte.

npm run setup

Te irá pidiendo, en este orden:

  1. Project URL y Publishable key: en Supabase, pulsa el botón Connect (arriba) o ve a Project Settings → API Keys. Copia y pega cada uno (en la terminal se pega con clic derecho o Ctrl+V). Nunca copies la Secret key: el asistente te avisará si lo haces.
  2. Iniciar sesión en Supabase: se abre el navegador; pulsa el botón de autorizar y vuelve a VS Code.
  3. Contraseña de la base de datos: la que guardaste en el paso 7. No se ve al escribirla (salen asteriscos).
  4. Un ajuste a mano: en Supabase → Authentication → Sign In / Providers → Email → desactiva Confirm email → Save. Así, mientras desarrollas, no hace falta confirmar el email para registrarse. Luego pulsa Enter. 
── Paso 4/6 · Crear las tablas (migraciones)
Applying migration 20260926000000_base.sql...
Applying migration 20260926000100_notes.sql...
── Paso 6/6 · Subir la función "borrar cuenta"
Deployed Functions on project abcdefghijklmnopqrst: delete-account

✅ ¡Listo! La app ya está conectada a tu base de datos.
Bien si… termina con ✅ ¡Listo! En Supabase → Table Editor verás las tablas notes y profiles.
¿Algo no va?
Falla en "Enlazar con tu proyecto" o "password authentication failed"
La contraseña no es la de la base de datos. En Supabase → Project Settings → Database → Reset database password, guarda la nueva y repite npm run setup.
Se cortó a medias o cerraste la ventana
Vuelve a ejecutar npm run setup. Es seguro repetirlo: lo que ya está hecho se salta.
Aviso en "Subir la función borrar cuenta"
La app funciona igual; solo el botón "Borrar mi cuenta" fallará. Repite npm run setup más tarde.
Parte 4 · ¡A verla!
9

Abre la app en tu móvil

2 min

Este comando pone en marcha el servidor de desarrollo. Mientras esté funcionando, tu móvil carga la app desde tu ordenador. Déjalo abierto mientras trabajas.

npm start
  1. Si Windows pregunta por el Firewall ("permitir que Node.js acceda a redes"), marca Redes privadas y pulsa Permitir.
  2. En la terminal aparece un código QR.
  3. Android: abre Expo Go → Scan QR code. iPhone: abre la cámara, apunta al QR y toca el aviso que sale.
  4. La primera carga tarda unos segundos. En la app, pulsa Regístrate y crea tu cuenta.
Bien si… entras y ves "Aún no tienes notas". Crea una. Si sale, tu app ya guarda datos en tu base de datos. 🎉

Para pararlo: Ctrl + C en la terminal. Mañana, para seguir, solo npm start.

¿Algo no va?
El móvil no conecta o se queda cargando
Comprueba que móvil y ordenador están en la misma wifi. Si es la wifi de una universidad, oficina o biblioteca, suelen bloquear esto. Para, y arranca en modo túnel (funciona en cualquier red, algo más lento):
npm run start:tunnel
Expo Go dice "Project is incompatible with this version of Expo Go"
Actualiza Expo Go desde la tienda de tu móvil.
La app dice "Configuración inválida"
Falta el paso 8. Ejecuta npm run setup y después npm start otra vez.
Al registrarte: "Sin conexión" o "Confirma tu email"
"Sin conexión": el proyecto de Supabase puede estar pausado (paso 7, Restore). "Confirma tu email": te faltó desactivar Confirm email (paso 8, punto 4).
Quiero verla en el ordenador
Con npm start en marcha, pulsa la tecla w: se abre en el navegador. Útil para ir rápido, pero prueba siempre en el móvil.
10

Haz tu primer cambio

2 min

Comprueba lo mejor de trabajar así: cambias el código y el móvil se actualiza solo.

  1. Con npm start en marcha, cierra sesión en la app (pestaña Perfil → Cerrar sesión).
  2. En VS Code, abre src/app/(auth)/sign-in.tsx (panel de la izquierda).
  3. Busca el texto Entra para ver tus notas. y cámbialo por lo que quieras.
  4. Guarda con Ctrl + S y mira el móvil.
Bien si… el texto cambia en el móvil en un segundo, sin hacer nada más.

Comprueba de paso que todo el proyecto está sano (tipos, estilo y tests):

npm run check

Y si algo va raro en cualquier momento, este comando revisa tu ordenador y te dice qué falta:

npm run doctor

Ya tienes tu app funcionando

Todo lo que has montado es gratis. Siguientes pasos cuando quieras:

  • Programar con Claude: descarga la app de Claude para Windows (claude.ai/download), entra en la pestaña Code, abre la carpeta del proyecto y escribe /empezar. Es lo único de pago de esta lista (necesita un plan de Claude, como Pro); lo demás no lo necesita.
  • Ponerle tu nombre: npm run rename -- "Mi App" com.tunombre.miapp
  • Entender cómo está hecha: abre docs/arquitectura.md en VS Code.
  • Cuando quieras enseñarla o publicarla: docs/graduacion/README.md (cada nivel dice lo que cuesta).
