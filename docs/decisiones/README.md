# Decisiones

Registro de decisiones de arquitectura importantes (en inglés, "ADR"): una página por decisión,
con el porqué y las alternativas descartadas. Sirve para que dentro de meses —o Claude en otra
sesión— no se deshaga algo sin saber por qué se hizo así.

- Plantilla: [`_plantilla.md`](_plantilla.md). Nombre: `NNN-titulo-corto.md` (001, 002…).
- Las propone la skill `/revisar-arquitectura`; también puedes pedirlo tú: "apunta esta decisión".
- Las decisiones de base de este proyecto (por qué Expo, Supabase, React Query…) están en
  [`../arquitectura.md`](../arquitectura.md#por-qué-estas-tecnologías).
