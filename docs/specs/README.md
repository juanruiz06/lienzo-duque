# Specs

Una spec es una descripción corta de una feature **antes** de construirla. Sirve para pensar,
para que Claude construya exactamente lo que quieres, y como memoria de por qué se hizo así.

- Copia [`_plantilla.md`](_plantilla.md) a `NNN-nombre-corto.md` (001, 002…), o pide `/planificar <idea>`.
- 1-2 páginas. Si crece más, divídela en fases.
- Cuando la feature esté hecha, cambia su estado a "hecho" y enlaza el PR.
